# Les Groupes, Fusions et Stages

Ce chapitre traite de la configuration des bénéficiaires de la formation.

## Les Groupes

Les groupes héritent des propriétés de leur filière, mais le système permet une personnalisation fine au niveau local.

- **Personnalisation des heures par groupe** : Ajustement du nombre d'heures hebdomadaires par module via "la liste des groupes pour persenaliser les nombres heures par semaine".

## Les Fusions

La mutualisation des cours permet d'enseigner à plusieurs groupes simultanément.

- **Les fusions** : Plusieurs groupes peuvent être réunis pour un même module d'enseignement.
- **Rendu** : Le système génère une session unique, allouant un seul formateur et une salle dimensionnée pour l'effectif global.

::: info Gestion des Stages
Le système gère nativement le calendrier d'alternance et les périodes de stage en entreprise.

- **Les groupes en stage** : Lorsqu'un groupe est ajouté dans les paramètres dédiés, le générateur l'ignore automatiquement pour la période définie.
- **Libération** : La vacance créée permet au système de redistribuer les formateurs et les salles vers d'autres priorités.
  :::
