# Prérequis Système

Avant de procéder à l'installation ou au développement du projet, assurez-vous que votre environnement respecte les spécifications suivantes.

## Environnement d'Utilisation

L'application finale est compatible avec les systèmes d'exploitation suivants :

- **Windows** (10 et 11)
- **Linux** (Distributions majeures via AppImage)
- **macOS** (Via DMG)

## Environnement de Développement

Si vous souhaitez compiler l'application ou contribuer au code source :

- **Node.js** : Version 18.0.0 ou supérieure recommandées.
- **npm** : Version 9.0.0 ou supérieure.
- **Git** : Pour le clonage du dépôt.
- **TypeScript** : Le projet est intégralement typé.

## Matériel Recommandé

- **Mémoire Vive (RAM)** : Minimum 4 Go (8 Go recommandés pour la compilation).
- **Espace Disque** : Environ 500 Mo pour l'application et ses dépendances.
