# Introduction

Le système de **Générateur d'Emplois du Temps** est une application bureau avancée conçue pour l'ISTA (Institut Spécialisé de Technologie Appliquée). Son objectif principal est de simplifier la création complexe d'horaires hebdomadaires en gérant automatiquement les contraintes logistiques et pédagogiques.

## Objectif du Projet

La planification des horaires dans une institution de formation professionnelle comme l'ISTA est un défi majeur. Les administrateurs doivent jongler avec :

- La disponibilité des formateurs.
- L'occupation des salles de cours spécialisées.
- Les modules spécifiques à chaque filière.
- Les périodes de stage des groupes.

Cette application centralise toutes ces données pour produire des emplois du temps cohérents, sans conflits et faciles à distribuer.

## Philosophie de Conception

L'application repose sur trois piliers fondamentaux :

1. **Fiabilité** : Utilisation d'un algorithme de vérification pour éviter tout chevauchement d'horaires.
2. **Accessibilité** : Une interface moderne construite avec React, offrant une expérience utilisateur fluide.
3. **Portabilité** : Une application autonome grâce à Electron, capable de fonctionner sans connexion internet permanente une fois installée.
